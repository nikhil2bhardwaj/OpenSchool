Theory

Homologous organs share a common bone plan (divergent evolution); analogous organs perform the same function with different plans (convergent evolution). The engine issues a deterministic verdict from the bone-pattern code.

Verdict = Homologous if bone-plan code matches, else Analogous (deterministic)

Precautions & Standard Errors

  • Compare internal anatomy, not external appearance or function alone.
  • Check embryological origin of each organ before concluding.
  • Use at least two independent trait lines (bones + development).
